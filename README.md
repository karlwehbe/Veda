# Veda

https://github.com/user-attachments/assets/b69d1394-21d8-45b8-855e-f4f8546f0c3c

Veda is an AI study assistant: you record a lecture, and it writes the study notes, places your slides in them, and
changes them when you ask in the chat.

The code is private. This repository only holds the design document, [DESIGN.md](DESIGN.md), which explains how Veda
is built and why.
